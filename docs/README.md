# docs

| 폴더      | 용도                                                      | 예시                                 |
| --------- | --------------------------------------------------------- | ------------------------------------ |
| `spec/`   | 기술 스택, 컨벤션 등 프로젝트 기본 문서                   | `tech-stack.md`, `git-convention.md` |
| `domain/` | 도메인 규칙과 서비스 핵심 정책 (도움 시간, 슬롯, 신고 등) | `help-time.md`, `survey-slot.md`     |
| `plan/`   | 스프린트·기능별 구현 계획과 작업 기록                     | `sprint-1.md`                        |

- 파일명은 kebab-case로 쓴다.
- 도메인 규칙은 PRD, 와이어프레임, 회의 결정 사항 중 확정된 내용만 적고 출처(PRD 항목, 화면 ID, 결정일)를 함께 남긴다.
- 규칙이 바뀌면 문서를 먼저 고친 뒤 코드를 바꾼다.
